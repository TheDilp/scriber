# Scriber - your local worldbuilding app

My one line pitch: keep everything on your device, fully private with unlimited storage (or however much you have), offline, for free.

## Features

- Projects: divide your work into separate projects
- Documents: rich text editor with extensive features
- Tags: Tag documents for easier grouping, filtering, sorting, search
- Document aliases: One document can be referenced by multiple titles

### Roadmap

- [ ] Search - find documents by title, across projects or within one project
- [ ] FTS - find specific text in documents across projects or within one project
- [ ] Canvas - create infinite canvases that can include documents, images, videos, gifs and make connections between them
- [ ] Smart lists - generate a list of documents based on filters such as tags, title, etc.
